# Setup: repo, shared code, tools

Table against image on the same grains: both near the ceiling, with an honest paired test.

Write `src/common.py` to the conventions in the context prompt, `Makefile`, `pyproject.toml`, `.python-version`, `.gitignore`, `tools/stamp_prompts.py`, `tools/check_prompts.py`.

`.gitignore` must exclude `data/raw/`, `data/derived/`, `.venv/`, `.claude/`, `docs/designs/`, `research/`, `results/smoke/`, `figures/smoke/`, `logs/`, and bulky model files not needed by `predict.py`.

Makefile targets: `help`, `data`, `grains`, `eda`, `features`, `cluster`, `baselines`, `neural`, `wedge`, `fit`, `freeze`, `compare`, `score`, `holdout-train`, `robustness`, `report`, `train` (= baselines + neural), `all`, `smoke`. `make help` lists targets and is the usage text. `wedge` runs HistGB `all106`, one SmallCNN seed and the validation comparison.

**GenAI record (brief section 8).** Each script is generated from a stage prompt saved in `prompts/NN-stage.md`, with fix prompts appended. Each generated file carries an "AI-generated" statement and the full prompt text in a header comment, because the brief requires "the prompt you used in full". `tools/stamp_prompts.py` copies the prompt file into the header, so nobody hand-copies; `tools/check_prompts.py` fails if they differ. The README, including the requirement map, is written by the group. `results/MANIFEST.csv`, generated by `make report`, lists requirement, stage and output file as raw material for it.

Stamp format: a comment block between `# === AI-GENERATED CODE: PROMPT RECORD START ===` and `# === AI-GENERATED CODE: PROMPT RECORD END ===` at the top of the file, stating the code was AI-generated and giving `prompts/00-context.md` and then the file's own prompt in full. Stamping is idempotent. Map: `src/NN_*.py` to `prompts/NN-*.md`; `src/common.py`, `tools/*.py`, `Makefile` to `prompts/setup.md`; `src/report.py` to `prompts/report.md`; `src/predict.py` to `prompts/10-predict.md`. `check_prompts.py` exits 1 if any header is missing or differs.
